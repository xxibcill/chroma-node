# [P20-T3] Library Browser And Search

## Status

Not started

## Phase

[Phase 20 - Look Library and Marketplace Foundation](../../roadmap/phase-20-look-library-and-marketplace-foundation.md)

## Outcome

Add a compact asset browser that lets users find, preview, and apply library items without leaving the Color page workflow.

## Scope

- Add search, filters, tags, favorites, recent items, and compatibility filters.
- Show thumbnails and short metadata for each item.
- Add hover or side-by-side preview on current frame where applicable.
- Add apply, inspect, duplicate, and reveal-source actions.

## Implementation Notes

- Keep the browser dense and workstation-native; avoid marketplace marketing layout.
- Use virtualized lists if large libraries become slow.
- Prevent thumbnails and metadata from shifting panel dimensions.

## Acceptance Criteria

- Users can search and apply a saved look within the Color page.
- Incompatible items are visibly disabled with a clear reason.
- Browser performance remains responsive with a large fixture library.
- Tests cover filtering, apply, and preview behavior.
